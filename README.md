# elforan2cdf — экспорт электрофореграмм Эльфоран в CDF (ANDI/AIA)

Конвертирует данные Эльфорана (Капель 105/205) в стандартный формат
**ANDI/AIA Chromatography netCDF** (`.cdf`, ASTM E1947). Такие файлы открывают
OpenChrom, Chromeleon, ChemStation/OpenLab, Empower, MZmine, Clarity и др.

Принимает:
- **`.mdf`** — родные файлы измерений Эльфорана. Выгружать в TXT не нужно; переносятся
  параметры анализа и таблица пиков;
- **`.txt`** — экспорт из Эльфорана (`Time  Signal  Current`).

## Что попадает в CDF

| Поле ANDI | Из .mdf | Из .txt |
|---|---|---|
| `ordinate_values` | массив `photometric` (mAU) | колонка `Signal` |
| шаг / задержка / длительность | `[Interval Time]` | колонка `Time` |
| `injection_date_time_stamp` | `[Measurement] Time` | из имени `…_ГГММДД_ЧЧММ` |
| `operator_name` | `Operator` | — |
| `dataset_origin` | прибор и заводской номер | — |
| `detection_method_name` | `UV <длина волны> nm` | — |
| `sample_id_comments` | капилляр, диаметр, длины, температура, комментарии | — |
| таблица пиков `peak_*` | `[Point_find…]`: время, начало/конец, высота, площадь, % площади, название, асимметрия, эффективность | — |
| `sample_name` | имя файла | имя файла |

Замечания:
- **Площадь пика** пишется в mAU·с, как требует стандарт. В Эльфоране площадь считается
  по точкам, поэтому её число в 1/шаг раз больше (при шаге 0,1 с — в 10 раз).
  Проценты площади совпадают.
- **Ток** в стандарте ANDI в тот же файл не кладётся (один детектор на файл);
  галочка/ключ `--current` сохраняет его отдельным `*_current.cdf` (мкА).
- **Кодировка** русских строк — UTF-8 (стандарт netCDF). Если старая программа
  показывает «кракозябры» — выберите cp1251.

## Программа с окном — Elforan2CDF.exe

1. «Добавить файлы…» или «Добавить папку…» — выбрать .mdf или .txt
   (или перетащить файлы/папку на значок Elforan2CDF.exe).
2. Где сохранять: рядом с исходным файлом или в выбранную папку.
3. По желанию — «сохранять ток», «переносить пики», единица сигнала для TXT, кодировка.
4. «Конвертировать». Результат и ошибки — в журнале внизу окна.

«Следить за папкой…» — указать папку, куда Эльфоран сохраняет измерения; пока окно
открыто, каждый новый или изменённый .mdf/.txt автоматически превращается в .cdf.

## Сборка .exe (на Windows-ПК)

1. Установить Python 3.8 или новее с https://www.python.org/downloads/windows/
   (при установке отметить «Add Python to PATH»). Для Windows 7 нужен именно 3.8.
2. Скопировать папку `elforan2cdf` на этот ПК и дважды щёлкнуть `build_exe.bat`.
3. В папке `dist` появятся:
   - `Elforan2CDF.exe` — программа с окном;
   - `elforan2cdf.exe` — консольная версия (для скриптов и автозагрузки).

Готовые exe самодостаточны: их можно копировать на компьютер с прибором,
Python там не нужен. Если антивирус ругается на свежесобранный exe —
это типично для PyInstaller, добавьте его в исключения.

### Если после сборки нет Elforan2CDF.exe (только консольная версия)

`build_exe.bat` сам проверяет типичные причины и пишет, что делать; полный журнал — `build.log`.

1. **Антивирус удалил файл** (самое частое). Windows Defender нередко считает свежие
   оконные exe от PyInstaller вирусом и молча удаляет. «Безопасность Windows» →
   «Защита от вирусов и угроз» → «Журнал защиты» → восстановить файл, или добавить
   папку `elforan2cdf` в исключения и запустить `build_exe.bat` снова.
2. **В Python нет tkinter.** «Параметры» → «Приложения» → Python → «Изменить» →
   «Modify» → отметить «tcl/tk and IDLE». Проверка: `python -c "import tkinter"`.
3. Окно можно запустить и без exe: `python elforan2cdf_gui.py`.

## Командная строка

```
python elforan2cdf.py "образец.mdf"              # рядом появится образец.cdf
python elforan2cdf.py D:\Эльфоран\Экспорт        # все .mdf и .txt в папке
python elforan2cdf.py --current -o D:\CDF *.txt  # + ток, результат в D:\CDF
python elforan2cdf.py --watch D:\Эльфоран\Экспорт  # автоконвертация новых измерений
python elforan2cdf.py --encoding cp1251 файл.mdf   # для старого Windows-ПО
```
